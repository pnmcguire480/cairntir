`tests/unit/test_managed_runtime.py` verifies every package hash and executes the frozen assertions. Run `python -m pytest tests/unit/test_managed_runtime.py -q`. With no `MANAGED_ACCEPTANCE_MODEL_CACHE`,25 cases run and the two real-model CLI cases explicitly skip. To execute all27, set that variable to an already-qualified local model cache. Each CLI fixture copies the cache into its disposable directory and enables offline mode; it does not download models or modify the supplied cache. Child processes use the same reviewed source package as the wrapper.

The original standalone commands remain `python test_managed_core.py`, `python test_managed_process.py`, `python test_managed_close.py`, and `python test_managed_config.py` from this directory, with the reviewed source on PYTHONPATH (or its installed interpreter), PYTHONUTF8=1, and the qualified cache variable for the latter process/config gates. `python oracle_controls.py` runs the independent pre-action oracle controls without importing candidate code. The maintained wrong-control runner expects an intentionally mutated disposable candidate on PYTHONPATH; ordinary source must never be mutated for this control.

The wrapper is maintained separately from the immutable acceptance bytes. Source-specific receipts in evidence/ identify the exact reviewed source and preserve failed attempts. Historical absolute paths in those receipts are evidence, not executable configuration. The native subprocess checks establish the managed runtime's commit and replay boundaries; they do not establish native coding-host delivery, arbitrary descendant containment, an OS sandbox, private evaluator custody, or the separately owed R10 generated projection.
