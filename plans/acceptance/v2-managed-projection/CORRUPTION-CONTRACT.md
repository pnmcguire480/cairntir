# R10 corruption supplement v1

Public post-review acceptance, frozen after the original eleven cases ran and
before these new cases execute. Original contract/tests and first result remain
unchanged. This makes “corrupt required evidence fails visibly” observable.

A required captured source with modified content or a missing referenced record
cannot produce a fresh successful view. A current checkpoint whose raw structured
metadata contradicts the committed task registry cannot be rendered as reconciled
truth. A close receipt whose public completeness/watermark fields contradict the
request bound by its workflow hash cannot certify complete capture. Error results
preserve an existing generated file and do not mutate any database rows.

Only disposable test fixtures are deliberately corrupted. This is consistency
validation, not resistance to an adversary rewriting every authoritative copy or
proof of historical raw text not hashed by legacy task protocols. No new runtime
or TaskBook behavior is required outside the projection's evidence-read boundary.

Separately scripted wrong controls challenge the existing frozen eleven cases:
invoking brief during rendering, dropping the human suffix, and falsely labeling
an absent close as complete. Each must fail its specific assertion, rather than
being counted merely because a process returned nonzero.
