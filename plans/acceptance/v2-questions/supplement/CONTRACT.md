# Public R08 failure-boundary supplement

Freeze before execution; keep all original acceptance unchanged. These checks cover load-bearing behavior missing from the first full-source run, not a reduced threshold. Invalid public payloads must fail as QuestionError before any drawer/workflow mutation. Exact committed acknowledgements and register state must not accept damaged original content, source identity, opening room, resolution text/ancestry or receipt bindings. A missing or secret required lifecycle drawer must withhold its group, never reopen it; an unchanged unrelated question remains visible. Authorized scoped writers must be able to open and explicitly resolve questions, while readers cannot append. Listing options are strictly typed. An append adapter that returns no persisted identity must not produce a committed acknowledgement or leave partial rows.

Use only disposable real SQLite stores and the existing synthetic HashEmbeddingProvider. Deliberate SQLite corruption is confined to fixture databases and tests how corrupted durable evidence is reported; it is not a claim of protection against an administrator rewriting both code and database. New cases must distinguish a typed failure from crashes or accidental success. Wrong control: bypassing original question receipt identity/hash matching must fail the frozen corruption witness. Preserve the original full-run coverage database and report before an additive coverage union; do not change coverage scope or floor. No product changes are planned or authorized by this packet.
