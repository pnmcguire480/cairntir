## Supply-chain posture

- GitHub Actions use immutable commit SHAs with human-readable major-version
  comments.
- PyPI publishing uses OIDC Trusted Publishing; no token is stored in the
  repository.
- Release artifacts receive GitHub build-provenance attestations before
  upload.
- Pushing a `v*.*.*` tag publishes automatically. Tagging is therefore a
  separate human gate, never part of local completion.
