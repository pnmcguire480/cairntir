## Why a PATCH

This release repairs install, first-run, policy, and documentation failures. It
adds no public API, MCP tool, schema migration, or embedding-space change. A
new user who cannot complete `cairntir setup`, or whose installed policy omits
default-layer memory, is the release-cadence exception that ships immediately.

## What is accepted

- `cairntir setup` succeeds when the Claude Code CLI is absent and configures
  whichever supported hosts are installed;
- Cursor user-scope setup prints the paste-ready User Rule;
- installed memory policy begins with `cairntir_handoff` and every repository
  copy is seam-tested against the source policy;
- first-run docs describe the shipped product rather than the v0.1 bootstrap;
- status, roadmap, plan map, MCP inventory, and the append-only release ledger
  agree on the current state and 20-tool surface;
- superseding an explicitly flagged open question closes it on the handoff read
  path without mutating the original drawer;
- the tokenizer-window eval uses Cairntir's production provider and anchored
  model cache, so the documented offline release gate tests the deployed path.
