# 1.12.4 maintenance release candidate

Status: **NOT PUBLISHED — qualification pending**. Prepared 2026-10-02.

This patch combines the existing stable baseline with PR122's dependency repairs
and reviewed diagnostics fixes. It adds no new runtime API, schema, model,
background service, remote access or automatic chat ingestion.

## Changes

- Locked AnyIO 4.14.2, PyJWT 2.15.1 and urllib3 2.8.0, retaining unrelated
  dependency records and platform markers.
- Locked sentence-transformers 5.6.0 and virtualenv 21.7.13, with required
  python-discovery 1.6.1, to repair new advisories reported by release CI.
- Doctor/status/version avoid automatic registration and update checks.
- Missing diagnostic stores remain absent. Status counts through a closed
  temporary read-only snapshot without constructing an embedding provider.
- Doctor distinguishes configured hosts from unverified live connections.
  Setup distinguishes its local write/read proof from semantic and host health.
- Contributor handoffs preserve dirty work and divergent branches.
- Existing baseline dependency-updater, MCP-major and pinned-action maintenance
  from Unreleased is included.

## Scope and limits

Acceptance follows existing repository release checks and focused regressions
for this maintenance patch. The earlier expanded cross-host pilot and proposed
resource-budget program are future work, not additional release prerequisites.
The parked 35-commitment v2 plan is neither included nor declared complete.

No new live cross-client, performance, native-host adoption or token/cost saving
claim is made. Configuration remains distinct from observed connectivity. Saves
remain explicit and acknowledged; this patch does not ingest unsaved chats.
Private stores and production bindings are unchanged. The proposed synthetic
Claude connection was cancelled before creating any fixture, grant or entry.

No migration or reindex is introduced by this patch. Heavy local qualification
is deferred for the host's thermal precaution; hosted CI uses clean environments,
synthetic fixtures and provisioned open model weights, without private stores or
separately billed model APIs. The normal [publishing checklist](../publish-checklist.md)
still applies to release and any later installation; unavailable operational
checks remain disclosed, not represented as passing native tests.
