# HumanFlow source and publication acceptance

These 25 cases restore the original R12 managed Python human-facing workflow:
20 expanded flow cases, one loopback transport case and four publication boundary
cases. They exercise actual managed Python integration execution, bound source
and trace evidence, draft validation, explicit publication, retry/currentness,
visibility/redaction, attribution and ambient-proxy/redirect rejection.

The three generic fixture files are preserved byte for byte. Their integration
stage imports the snapshot implementation and runs actual Python checks; their
other stage families are controlled fixtures. Narration uses an inert adapter or
controlled loopback responses. This suite does not qualify a real model, native
observer, or actual lint/type/build tool efficacy.

Original case/helper bodies, assertions, parameters and deadlines retain their
ASTs. Only import/bootstrap paths and borrowed helper pins are adapted to this
public checkout. The existing public PALADIN helper canonicalizes its selected
Python executable, relocates its local controlled-stage file, checks equal zip
lengths and uses list() for an ordinary list copy. Its controlled-stage helper
has the original AST with formatting changes. R12 replaces each stage helper
with the preserved run_stage.py and updates that declared input hash.

This source restoration does not inherit the original protected R12
qualification. Current focused/combined execution and independent source review
must be recorded separately. Keep fixture/ byte-exact and excluded from outer
formatting; it is executed only as the workflow's bound input.
