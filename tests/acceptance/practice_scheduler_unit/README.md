# Practice scheduler behavior controls

Six preserved scenarios exercise stage observation intake, restart-safe review
queues, explicit schedule supersession, tampered evidence refusal, access
boundaries, early review proposals, completion reset and unattended CLI ticks.
All stores, practices, observations and evaluator outcomes are synthetic.

The stage intake case imports the shared public `paladin_python_unit` fixture
in its default controlled mode. Its child writes synthetic stage reports; it
does not run Ruff, pytest or a package build. These checks exercise Cairntir's
scheduler, evidence and refusal behavior. They do not qualify field duration,
real toolchains, host installation, live models or autonomous efficacy.

This package contains no private acceptance histories or execution receipts.
Test execution and independent review are recorded separately.
